**Status: phase-0 vertical slice, macOS arm64.** Nova Engine Studio is the native editor shell for Nova Engine. It is not a Unity wrapper, an Electron app or a mock layout: hierarchy, Scene/Game views, inspector and console all read the same live `World` value.

Every panel is drawn by [nova-gui](../../libraries/gui/) from Nova code. The project is the first editor-facing slice of the engine, not a finished product.

## What is real

- **One World.** The hierarchy lists live entity slots and their generation handles. Selection, inspector fields, play/pause/step and the console all read the same `world.nova` value.
- **Two view states.** Scene draws the perspective grid, wireframes, selection colour and entity labels. Game hides the editor grid, selection overlay and labels while keeping the same entities.
- **Real time controls.** `Space` plays or pauses, `S` advances one fixed 1/60 s tick, `Tab` cycles live entities, `Delete` despawns the selection, and `R` resets the demo world.
- **A native shell.** The installer produces `Nova Engine Studio.app` with an icon and an ad-hoc signature. There is no web view, Electron or JavaScript runtime.

## Run it

Use the compiler built from the current sources; the checked-in stage-0 bootstrap predates the shell and Metal support.

```sh
# from the repository root
(cd examples/nova-tool && ../../bootstrap/nova build)
cd examples/scene-gui
../../examples/nova-tool/target/nova/nova-tool build
./target/nova/scene-gui
```

Install the signed local app:

```sh
cd examples/scene-gui
sh install-macos.sh
open "/Applications/Nova Engine Studio.app"
```

The bundle is ad-hoc signed, not Developer ID signed or notarized. On first launch macOS may require right-click → **Open**. The installer falls back to `~/Applications` when `/Applications` is not writable.

## Capture test

```sh
cd examples/scene-gui
sh tests/shell.sh
```

The test captures both tabs at 2880×1800, checks the traffic-light row through `NOVA_GUI_TRACE`, enters Game through the same mouse-down hit test as the window, and samples 12 pixels: panel surfaces, both active-tab states, the selected hierarchy row, a Scene grid line that becomes plain background in Game, and the drawer. Both PNGs are left in `target/` for review.

The title strip calls `gui.place_traffic_lights(14)` and reserves 84 points on the left, so AppKit's close/minimize/zoom buttons do not overlap the title or menu. AppKit's own event delivery is still a manual check; the capture test verifies the handler below it.

## Honest gaps

- **The viewport is a CPU preview.** It projects Q16.16 transforms through `mat4_perspective` and `mat4_look_at` into Nova GUI lines. The lit Metal cube lives in `examples/metal-lab`; embedding it in Studio is the next slice.
- **The inspector is read-only.** Add Component reports that no component types are registered yet. There is no undo or redo.
- **Game is a view state, not a build.** It does not simulate a separate runtime camera, package a player or handle input as a game.
- **No save/load or docking.** The six-entity demo world is created in code each launch.
- **macOS arm64 only.** The host uses AppKit, CoreGraphics and CoreText, with Metal support in the separate engine lab.
