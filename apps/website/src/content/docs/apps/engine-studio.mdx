**Status: phase-0 vertical slice, macOS arm64.** Nova Engine Studio is the native editor shell for Nova Engine. It is not a Unity wrapper, an Electron app or a mock layout: hierarchy, Scene/Game views, inspector and console all read the same live `World` value. The centre viewport is an offscreen Metal render composited into the same Nova GUI bitmap as the editor chrome.

Every panel is drawn by [nova-gui](../../libraries/gui/) from Nova code. The project is the first editor-facing slice of the engine, not a finished product.

## What is real

- **One World.** The hierarchy lists live entity slots and their generation handles. Selection, inspector fields, play/pause/step and the console all read the same `world.nova` value.
- **A Metal viewport.** The Scene/Game centre is an offscreen Metal render, not a CPU wireframe. Studio builds one Q16.16 model-view-projection matrix per live entity and submits a bounded draw list to `runtime/metal.m`; the host renders depth-tested lit checker meshes with one directional light. The frame is read back at the display's backing scale and composited into the same sRGB bitmap as the panels, so `gui.save_png` captures the viewport and the editor together. It is an offscreen render, not an embedded `MTKView`.
- **Two view states.** Scene draws the perspective grid, selected-player box and entity label over the Metal frame. Game hides those editor overlays while keeping the same six entities and Metal scene.
- **Real time controls.** `Space` plays or pauses, `S` advances one fixed 1/60 s tick, `Tab` cycles live entities, `Delete` despawns the selection, and `R` resets the demo world.
- **A native shell.** The installer produces `Nova Engine Studio.app` with an icon and an ad-hoc signature. There is no web view, Electron or JavaScript runtime.

## Run it

Use the compiler built from the current sources; the checked-in stage-0 bootstrap predates the shell and Metal support.

```sh
# from the repository root
(cd examples/nova-tool && ../../bootstrap/nova build)
cd examples/scene-gui
../../examples/nova-tool/target/nova/nova-tool build
./target/nova/scene-gui
```

Install the signed local app:

```sh
cd examples/scene-gui
sh install-macos.sh
open "/Applications/Nova Engine Studio.app"
```

The bundle is ad-hoc signed, not Developer ID signed or notarized. On first launch macOS may require right-click → **Open**. The installer falls back to `~/Applications` when `/Applications` is not writable.

## Capture test

```sh
cd examples/scene-gui
sh tests/shell.sh
```

The test captures both tabs at 2880×1800, checks the traffic-light row through `NOVA_GUI_TRACE`, enters Game through the same mouse-down hit test as the window, and samples 15 pixels: panel surfaces, both active-tab states, the selected hierarchy row, the Metal clear colour, two checker-texture colours, a Scene grid overlay that becomes Metal background in Game, and the drawer. It also runs five live frames through `NOVA_SCENE_FRAMES` and requires `live=stopped frames=5 viewport=metal`. Both PNGs are left in `target/` for review.

The title strip calls `gui.place_traffic_lights(14)` and reserves 84 points on the left, so AppKit's close/minimize/zoom buttons do not overlap the title or menu. AppKit's own event delivery is still a manual check; the capture test verifies the handler below it.

## Honest gaps

- **The editor camera is fixed.** Studio renders the Metal scene from one Q16.16 perspective camera. Orbit, pan and zoom are verified in `examples/metal-lab`, but Studio does not poll those camera-input slots yet.
- **The inspector is read-only.** Add Component reports that no component types are registered yet. There is no undo or redo.
- **Game is a view state, not a build.** It does not simulate a separate runtime camera, package a player or handle input as a game.
- **No save/load or docking.** The six-entity demo world is created in code each launch.
- **No GPU timing or advanced renderer.** The viewport has one directional light, one texture slot, no MSAA, shadows, normal mapping, mipmaps or asset pipeline.
- **macOS arm64 only.** The host uses AppKit, CoreGraphics, CoreText and Metal.
