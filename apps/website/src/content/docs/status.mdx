## Verification snapshot

- Compiler: the checked-in `bootstrap/nova` builds the toolchain and the rebuilt compiler reproduces byte-identical IR. `codegen.sh` passes 262/262 and `diff.sh` 18/18; the LSP is a Nova implementation.
- Nova tooling: `examples/nova-tool/tests/toolchain.sh` (126 assertions) and `boxes.sh` (64 assertions) cover the Nova formatter, lexer, parser, checks, archives and registry reads.
- Nova Writer: 97 headless core assertions, a two-process crash-recovery test, 14 IME commit/cancel assertions and a native-window snapshot pass; the installed bundle is ad-hoc signed. Interactive typing, selection and clipboard remain manual checks.
- Editor: `npm run typecheck`, `npm run build` and DMG/NSIS packaging pass. The installed Homebrew app was not GUI-automated.
- VS Code extension: TypeScript typecheck, VSIX packaging, `code --install-extension` and a live `nova lsp` transcript (initialize, open buffer, `E0308`, shutdown) pass. Extension Host interaction is not automated.
- Browser playground: the checked-in WASM artifacts pass valid/invalid source checks and the static route check. A Nova wasm backend and native execution remain gaps.
- Website: `astro check`, production build, base-path/link verification and checked snippet compilation are CI gates.
- Deployment: public repository [jd4rider/nova](https://github.com/jd4rider/nova); GitHub Pages build and deploy completed successfully. Live site: [jd4rider.github.io/nova](https://jd4rider.github.io/nova/).
- Releases: [v0.2.0](https://github.com/jd4rider/nova/releases/tag/v0.2.0) has an unsigned macOS DMG, Windows NSIS EXE, CLI archives and the `nova-language-0.2.0.vsix`. The Homebrew cask was verified at 0.1.0; the tap has not been bumped to 0.2.0 yet.

Reports of a claimed feature without evidence should be treated as a documentation bug.
