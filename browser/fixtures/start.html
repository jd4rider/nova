Nova Browser

WebKit is online.

Nova owns the window, tabs, address bar and history. WebKit owns this page. The trusted fixture has no remote resources, so everything here works offline.

Nova documentation

The language, libraries and toolchain this browser is built with.

Import from Google Chrome

Press Cmd+Shift+I to pull bookmarks from your Chrome profiles. Bookmark this page with Cmd+D.

Type to find

The address field ranks local bookmarks and visits as you type. Enter opens, Tab completes, ↑/↓ moves.

Switch tab layout

Cmd+Shift+E flips between a horizontal strip and a vertical column. The choice is remembered.
