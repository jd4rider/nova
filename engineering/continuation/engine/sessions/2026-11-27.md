# 2026-11-27 — Inspector edits and undo (ENG-04.003)

Starting point: Studio 0.3.0 had the offscreen Metal viewport, real hierarchy
selection, a live inspector and console, but the transform rows were read-only.

1. **Editable transform rows.** Position, Rotation and Scale are now inline
   fields. Clicking a row uses the same inspector hit test as any other mouse
   action; composed text arrives through `event_text`/`typed_text`. Enter parses
   three or four comma-separated decimals into Q16.16 and commits through
   `world_set_position/rotation/scale`; Escape cancels; invalid input keeps the
   field active.
2. **Editor-only command history.** Each commit stores
   `EditCommand { entity, field, before, after }`. A 16-entry stack in `App`
   replays the before or after value; a new edit truncates redo. Undo/Redo
   buttons and ⌘Z/⇧⌘Z share the same path. The runtime World has no undo state.
3. **Capture acceptance.** `tests/shell.sh` now captures base, edit, undo and
   redo. It checks `history=1/1 → 0/1 → 1/1` and the printed Position, then
   compares only the Scene viewport crop so inspector chrome cannot mask a
   world change. Undo must equal the base crop; edit must differ; redo must
   equal the edit crop.
4. **Language snag.** The first build rejected `app = edit_commit(app)` in
   `handle_mouse_down` because function parameters are immutable. A local
   `var app = app` fixes the click-commit path; no runtime or GUI-host change
   was needed.
5. **Shipped.** Studio 0.4.0 installed at `/Applications/Nova Engine Studio.app`,
   signature verified. Installed base/game/edit/undo/redo captures are
   byte-identical to the local test captures.

Limits: history is per-session and single-field; no multi-select, grouped
commands, gizmo, persisted undo, prefab or scene save/load. The editor camera is
still fixed. Next is ENG-04.004, dockable panels.
