# Nova Writer — 2026-11-27

## Objective

Land WRI-07.005: stop restoring unsaved work silently, add a native recovery
prompt with a safe keep path and an explicit discard path, and test the real
modal rather than a bypass.

## Work completed

1. Added a native `NSAlert` bridge to `runtime/gui.m` in begin/button/run
   calls. It supports up to three buttons, returns 1/2/3 for the chosen button
   and 0 for dismissal, and maps Escape to the second (safe) button.
2. Added `gui.alert(title, message, primary, secondary, tertiary)` to
   `libraries/nova-gui`.
3. Startup now asks Recover, Keep for Now or Discard when snapshots exist.
   Recover restores up to six dirty tabs; Keep/dismissal records the pending
   paths without deleting them; Discard removes only the prompted snapshots.
4. Added a conditional `Discard` ribbon command for pending snapshots. It
   confirms with a second alert and removes only the paths recorded at startup,
   so later autosaves are not swept away.
5. Added `writer/tests/recovery-prompt.sh`, which seeds real recovery files and
   drives the real alert through recover, keep, discard, and dismiss-then-
   command paths. Added the `NOVA_WRITER_COMMAND_PROBE` test hook.
6. Reinstalled `/Applications/Nova Writer.app` and verified the installed
   bundle restores through the prompt.
