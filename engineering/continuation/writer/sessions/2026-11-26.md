# Nova Writer — 2026-11-26

## Objective

Land the first real vertical slice: a native Nova-built Writer window over a
GUI-independent document core with measured pagination, editable paragraphs,
bounded undo, a native `.novadoc` round trip, and an installed app bundle for
owner testing.

## Work completed

1. Audited the existing GUI host, `nova-gui`, Boxes, Browser and Studio.
   Recorded capabilities and gaps in `AUDIT.md`.
2. Probed the compiler: `chars()` and `List<String>.join` work; `graphemes()`
   is absent; snapshots are value-independent; qualified struct literals are
   rejected. Implemented grapheme segmentation in Nova.
3. Extended the host with styled CoreText runs, measured advances and atomic
   rename; added matching Nova wrappers.
4. Implemented `@nova/document`: text, document model, layout, store.
5. Implemented the Writer app: tabs, ribbon, ruler, sidebar, pages, editing,
   selection, clipboard, undo/redo, save/open, zoom, themes, paper, outline,
   accessibility labels, autoclose/snapshot hooks.
6. Built, smoke-tested, packaged, ad-hoc signed and installed
   `/Applications/Nova Writer.app` (0.1.0).
7. Fixed three interaction bugs found during review: Shift-click anchoring,
   active-tab index after closing a tab, and CRLF normalization on paste.
   PageUp/PageDown now scroll about one viewport.
8. Added autosave and crash recovery (WRI-07.003): `recovery.nova`, host epoch
   and delete helpers, a two-process crash test, startup restore, and a 4-second
   atomic autosave loop. Reinstalled and verified the installed bundle.
9. Fixed a wiring bug found by the recovery snapshot: `wr_start` returned the
   App literal before `wr_restore`, making recovery unreachable. The App is now
   assigned to a local and returned through `wr_restore`.
10. Added IME marked-text composition (WRI-03.004): the host clears marked text
    on Escape, Writer paints the preedit through a temporary document/layout so
    it reflows inline, commits `insertText:` exactly once, and leaves the
    document untouched on cancel. Added `writer/tests/ime.sh` with a host probe
    that drives both entry points; 14 assertions pass.
11. Added `.novadoc` v2 schema migration (WRI-02.005): a persisted document
    language, v1-to-v2 migration on load, rejection of v2 files without the
    field and unknown versions, and tests for both header versions.
12. Added WRI-04.002 typography: `.novadoc` v3 stores per-paragraph
    auto/LTR/RTL direction; v1/v2 migrate. Layout aligns and maps the caret
    from that direction, the sidebar exposes Auto/LTR/RTL, the demo includes
    Hebrew/Arabic/CJK text, and the core suite covers mixed-script fallback,
    RTL caret geometry and CJK wrapping. Reinstalled the bundle.

## Decisions

- DEC-WRI-002 `.novadoc` v3 text container with v1/v2 migration; ZIP later.
- DEC-WRI-010 per-paragraph auto/LTR/RTL direction; auto uses the first strong
  character, and caret/alignment follow the paragraph base direction.
- DEC-WRI-003 bounded snapshot undo (core: `Document`; app: serialized
  snapshots because of the compiler limit, DEC-WRI-006).
- DEC-WRI-004 CoreText shapes and measures; Nova owns layout.
- DEC-WRI-005 no fake controls.
- DEC-WRI-007 install each phase to `/Applications` for owner testing.
- DEC-WRI-008 autosave is a full `.novadoc` snapshot every 4 seconds under
  Application Support, epoch-named, with startup auto-restore.
- DEC-WRI-009 the host owns marked text; Writer paints it from a temporary
  layout and owns the single commit/cancel transition.

## Blockers / limits

- The compiler now supports `List<Document>` fields; the app still uses
  `List<String>` snapshots (DEC-WRI-006) and can switch later. Index assignment
  through a struct field still uses a local copy (`wr_put`).
- No `NSSavePanel` bridge; Save As is a folder picker with unique filenames.
- No alert bridge, so recovery auto-restores without a prompt and has no
  discard command.
- No accessibility text ranges, inline runs, tables, images, headers/footers,
  or DOCX/PDF. IME composition is painted from a temporary layout and is not
  in the document until commit.
- Autosave rewrites the full document every 4 seconds; no external-change
  detection or encryption.
- Mixed-direction caret positions inside one line are approximate; CJK breaks
  are grapheme-based, not full UAX #14, and there is no hyphenation.
- GUI interactions are not automated; only launch/rendering is machine-checked.
