# Session 2026-11-25

## Result

The Nova tool now self-builds through three generations. This is behavioral
bootstrap evidence for the Nova driver, parser, sema and codegen; it is not a
claim of full compiler/LSP parity or a Rust-free toolchain.

- Stage 1: the Rust-built `nova-tool` compiled itself to `/tmp/nova-self`.
- Stage 2: `/tmp/nova-self` compiled itself to `/tmp/nova-self-2`.
- Stage 3: `/tmp/nova-self-2` compiled itself to `/tmp/nova-self-3`.
- Each generation built `tests/codegen-sample.nova`; the native program exited
  9. The three SHA-256 hashes differ, so no byte-identical fixed-point claim.

## Fixes and features added

- Qualified module calls (`gui.read`, `math.double`) resolve to the flattened
  global function after an aliased import; sema and codegen agree.
- Expression-valued `if`/`else` lowering with a merge value and better
  unsupported-expression diagnostics.
- `%` lowers to `srem`.
- `char_string`, `json_string` and `http_get` builtins lower to existing
  runtime symbols; native builtin fixture returns 5 and `http_get` compiles
  without a network request.
- The Nova driver detects host symbols and links `runtime/gui.m` on Darwin
  with the same Cocoa/CoreText/CoreGraphics/ImageIO/QuartzCore frameworks as
  the Rust bootstrap.
- Mutable list bindings and list reassignment now clone their backing storage
  through `nova_list_clone`; `cg_struct_cycle` no longer relies on a shallow
  header copy. A regression fixture pushes through two copies of one list and
  returns 7.

## Nova LSP diagnostics slice

`libraries/nova-lsp/src/lsp.nova` now implements the first real LSP surface:
Content-Length-framed JSON-RPC over stdio, `initialize` with full-document sync
and completion, `shutdown`/`exit`, document open/change/save/close,
`textDocument/publishDiagnostics` backed by the Nova parser/sema slice, and
completion for keywords, builtins, declarations and `.` members. Runtime stdin
primitives were added to `runtime/runtime.c`.

`tests/lsp.sh` sends a real protocol transcript, verifies `E0301` on an invalid
buffer, no diagnostics after the fix, diagnostics cleared on close, and
completion items including `helper`, `main`, `fn` and `println`. It passes
against the seed-built `nova-tool`, `/tmp/nova-self` (generation 1),
`/tmp/nova-self-2` (generation 2) and `/tmp/nova-self-3` (generation 3).
Hover, definition, formatting and `nova lsp`/Studio wiring remain.

Codegen now appends IR through `nova_ir_reset`/`nova_ir_line`/`nova_ir_take`
and joins function bodies once, instead of cloning the growing line list per
line. Stage-1 self-build fell from 5.84 GB / 2.48s to 1.67 GB / 1.60s.
